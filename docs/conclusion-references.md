# Conclusion & References

## Conclusion

*The Tapestry of Monyul* demonstrates how Gross National Happiness
values and Bhutanese cultural heritage can be embedded directly into
game mechanics rather than delivered through passive textbook-style
content. The project's Agile, sprint-based development process —
validated by a fully passing automated test suite (80/80) — reflects
professional software engineering practice applied to a
culturally-grounded educational game. Development made significant use
of AI-assisted implementation tools (Ziva), which shaped both the
project's productivity and its iterative development workflow.

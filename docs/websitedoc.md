## 5. Making of the Documentation Website

### 5.1 Platform & Hosting Architecture
To meet the **TechTrek 2026 Guidelines**, the official project documentation is published online and hosted directly via **GitHub Pages**.

* **Documentation Framework:** Built with Markdown files hosted within the repository's `/docs` directory and deployed via GitHub Pages.
* **Repository:** Source code, assets, and documentation maintained in a public GitHub repository.
